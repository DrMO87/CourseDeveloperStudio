# Agent Memory — read before you work this vault

## Owner role — read this first, every time

**The owner is not the course's domain expert.** Agents own technical sourcing,
content critique, asset selection, quality control, and defects they can resolve.
Do not ask the owner to validate a platform fact or repair an agent-produced
artifact.

- **Never hand the owner an agent-resolvable defect and call it his.** If an
  agent can plausibly check or fix it, the agent does so.
- **Reserve the owner only for** a decision with no correct answer derivable
  from the approved sources and contracts, or a literal physical action only
  the owner can take.
- When technical reviewers can settle a question, use the approval-record
  process in the course contracts instead of escalating it to the owner.
