# 📖 Student Take-Home Summary: HPLC

## 🌟 Key Concepts & Formula Cheat Sheet
$$R_s = \frac{2(t_{R2} - t_{R1})}{W_1 + W_2} \ge 1.5 \quad (\text{Baseline Separation})$$
$$\text{Asymmetry Factor } A_s = \frac{b}{a} \quad (\text{at } 10\% \text{ peak height, ideal } 0.9 - 1.2)$$
$$\text{Linearity }: y = m x + c \quad (R^2 \ge 0.999)$$

- **Core Rule**: In Reversed-Phase HPLC (RP-HPLC), more polar drugs elute first, while lipophilic analytes are retained strongly on C18 chains.
- **Practical Takeaway**: Mobile phase: Acetonitrile : 1% Chloroacetic acid buffer (60:40 v/v), Flow rate: $1.5\text{ mL/min}$, Detection: $254\text{ nm}$.
